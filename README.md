This project is a computer vision-based fitness assistant that counts dumbbell curls in real time using a webcam or video input. It uses MediaPipe for pose detection and OpenCV for video processing and UI rendering.

🤖NOTE:
Use any type of exercise video for this project for better understanding

🚀 Features:

Detects human body pose using MediaPipe.

Calculates the angle of the arm during dumbbell curls.

Dynamically interpolates movement to measure exercise completion percentage.

Counts reps accurately using arm curl logic.

Displays real-time FPS and repetition counter.

Can work with a webcam or pre-recorded video.

🧠 Requirements:

Python 3.7+

OpenCV

MediaPipe

NumPy
